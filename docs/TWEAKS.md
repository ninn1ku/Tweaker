# Каталог твиков

> Файл генерируется скриптом build/New-TweakDocs.ps1 из config/tweaks/*.json. Не редактируйте вручную.

Всего твиков: **64**

Риск: «Безопасно» — можно применять всем; «Умеренно» — есть компромиссы, читайте описание; «Для опытных» — только если понимаете последствия. «не проверен» — поведение не подтверждено на актуальных сборках, такие твики не входят в пресеты.
